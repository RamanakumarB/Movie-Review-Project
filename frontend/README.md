# Movie Review UI

A responsive React frontend for the Movie Review Application. This UI allows users to browse a catalog of movies, watch YouTube trailers, and submit reviews in real-time.

## Tech Stack
* **React 18**
* **React Router DOM** (for navigation)
* **Axios** (for API integration)
* **React Bootstrap & Material UI** (for styling and carousel)

## Features
* **Hero Carousel:** Browse featured movies.
* **Trailer Integration:** Watch embedded YouTube trailers directly within the app using `react-player`.
* **Interactive Reviews:** Submit and view movie reviews fetched from the Spring Boot backend.

## Setup Instructions
1. Clone this repository.
2. Ensure the Spring Boot backend is running on `localhost:8080`.
3. Run `npm install` to download dependencies.
4. Run `npm start` to launch the application on `localhost:3000`.
